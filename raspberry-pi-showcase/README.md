# Raspberry Pi Showcase

A responsive static Raspberry Pi 5 landing page. Open index.html directly in a browser or serve this folder with any static file server.

## UI interactions
- Responsive mobile navigation
- Project idea picker with keyboard arrow navigation
- Memory option selector that updates the model summary
- Expandable FAQ answers

No build step or backend is required. The product-style image is included in assets. Official Raspberry Pi product, documentation, and project pages are linked from the UI. Specs and list prices are based on Raspberry Pi's official product information; local prices and availability may vary.
