# Neon Drop

A standalone, browser-based Tetris game with a calm, late-night arcade interface. No install or build step is needed: open `index.html` in a browser.

## Controls

- Left / Right arrows or A / D: move
- Up arrow or X: rotate
- Down arrow or S: soft drop
- Space: hard drop
- C: hold or swap the current piece
- Escape or P: pause / resume
- Enter: start or play again

The on-screen buttons work on touch devices. Your best score is saved in the browser's local storage.
