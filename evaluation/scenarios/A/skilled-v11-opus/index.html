Each endpoint gets its own alert threshold

One latency alert for a whole API is too noisy for slow endpoints and too quiet for fast ones. Set a threshold per endpoint and send it where the right people will see it: Slack, PagerDuty or email.

Example alert thresholds per endpoint. Editing a threshold updates the status against the sample p95 values.
