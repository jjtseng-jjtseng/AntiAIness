    Formatting happens as you type

    There’s no toolbar to hunt through. Start a line with a symbol and it becomes a heading, a list or a to-do. Put # in front of a word to tag the note, or a note’s title in double brackets to link to it.

    Typing shortcuts in Notely
    You typeYou get
    At the start of a line, then a space
    #A heading
    -A bulleted list
    [ ]A to-do you can check off
    Anywhere in a note
    #errands#errandsA tag, collected in the sidebar
    [[Kitchen quote]]Kitchen quoteA link to that note
    With a keyboard
    ⌘KSearch every note

    Find a note by the one detail you remember

    Search looks through every title, line and to-do, checked or not, and marks each match in yellow, in the list and inside the note, so you can see why a note turned up before you open it.

    When what you find is a code, you can read it off correctly. Notes are set in Atkinson Hyperlegible Next, a typeface the Braille Institute designed for readers with low vision, in which letters that look alike in most fonts are drawn to be told apart.

    Tags and links, only when a note needs them

    Tag a note and everything with the same tag is one click away in the sidebar. Link one note from another and the link works in both directions, so the kitchen quote knows the plumber note mentions it.

    Neither is required. A note with no tags still turns up in search.
