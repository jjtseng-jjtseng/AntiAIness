Notes that stay findable.

Notely is a note-taking app for people who write a lot and look things up more. Every note is plain text, indexed as you type, and linked to the notes it mentions.

Start writing See how search works

Write without leaving the keyboard

A note starts with a title and a blank line. Headings, lists and checklists come from the same punctuation you would type in a text file, and Notely formats them as you go, so there is no toolbar to reach for and nothing to undo later.

Type two square brackets and the name of another note to link to it. If that note does not exist yet, Notely creates it the first time you follow the link.

What you type, and what it becomes
# at the start of a lineA heading
- or 1. A bulleted or numbered list
- [ ] A checklist item
[[Note title]]A link to another note
#baking anywhere in the noteA tag
⌘NNew note
⌘KSearch, or jump to a note by title

Search every word of every note, as you type

Notely indexes a note while you are still writing it. Searching for a word shows the notes that contain it with the matching line underneath, so you can usually find what you meant without opening anything.

Narrow by tag with #baking, or by date with before:october. Results are sorted by how recently you edited the note, because the note you want is almost always the one you touched last.

  • Sourdough — attempt 312 Oct

  • Sourdough — attempt 128 Sep

Every note knows which notes mention it

When you link to a note, the link shows up at the bottom of the note you linked to. Open last month's attempt and you can see this week's, without having remembered to link back.

That is the whole system. There are no folders to maintain and no hierarchy to decide on; notes connect because you referred to one while writing another.

Sourdough — attempt 3

Went to 80% hydration and it spread in the oven. Crumb was open but the loaf was flat. Back to 75% next time.

Linked from 2 notes

  • Sourdough — attempt 4
    Fed the starter at 7:40 at 1:5:5, same as Sourdough — attempt 3.
  • Weekly review
    Didn't go well: Sourdough — attempt 3. Try a lower hydration before changing anything else.

Your notes are files you own

Notely keeps each note as a plain text file in a folder you choose. You can open the folder in any editor, back it up however you back up everything else, and leave Notely at any time with nothing to export.

Plain text
One .md file per note. Headings, lists and links are ordinary Markdown.
Works offline
Writing and search run on your device. No account is needed to use the app.
Nothing locked in
Links between notes are written into the files as [[Note title]], which other Markdown tools also understand.
