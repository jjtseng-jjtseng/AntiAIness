# Scenario D: game interface

Build a static mock of the UI for "Hollow Vale", a browser roguelike dungeon crawler with a dark-fantasy pixel-art world rendered in a 16-color palette. Aesthetic requested: "it should feel like the game itself, retro pixel-art and dark fantasy; not like a website or a dashboard."

Required in one page: (1) the title screen with the game name, "New run", "Continue", "Settings", and a line showing the last run ("Floor 7 · 2,340 gold · 18:24"); (2) the in-game HUD overlaid on a placeholder game viewport (a 16:9 area you may fill with a simple CSS/SVG dungeon scene or a flat color) showing HP 34/50, Stamina 3/5, Gold 412, Floor 4, a 3-slot item bar (Torch, Rusted Key, Potion ×2), a minimap placeholder, and a short message log ("You descend. The air is colder."); (3) the pause menu (Resume, Settings, Abandon run). Keyboard hints may be shown. Pixel-art conventions (crisp edges, limited palette, bitmap-style type) are expected.
