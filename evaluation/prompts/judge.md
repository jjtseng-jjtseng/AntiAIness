# Judge prompt (fresh agent, unlabeled variants)

You are reviewing rendered screenshots of web interfaces. For each scenario you get the brief and two (or three) variants labeled only V1/V2(/V3), in random order. You do not know how each was produced. For each scenario:

1. Describe in two sentences what each variant's design is attempting.
2. Rate each variant on these qualities with one of: weak / adequate / strong, and one sentence of justification each:
   - visual quality (craft: alignment, type, color, spacing)
   - fidelity to the requested style in the brief
   - coherence (one direction carried through)
   - product specificity (could this only be this product?)
   - distinctiveness (would you remember it?)
   - usability (hierarchy, readability, obvious actions)
   - accessibility floor as visible (text size, contrast)
   - responsive behavior (compare desktop and mobile renders)
3. List concrete patterns in each variant that you associate with template-like or AI-generated interfaces (be specific: name the element and where it is).
4. State which variant you would ship for this brief and why, in three sentences. If neither, say so.

Do not infer anything from file names. Judge only what is visible.
