# Scenario C: playful or creative interface

Build "Sumwise", a browser math practice game for children aged 7–9 (addition and subtraction up to 100). Aesthetic requested: "colorful, playful, friendly, kid-appropriate; parents and teachers should find it trustworthy; must be usable on a tablet."

Required screens in one page (show both, stacked or toggled): (1) a home screen with the game name, a "Play" action, a choice between Addition / Subtraction / Mixed, and a place for the child's name and star count (for example "Maya · 12 stars"); (2) a problem screen showing one problem (47 + 28 = ?) with four answer choices (75, 65, 85, 74), a progress indicator (problem 3 of 10), a hint control, and feedback states for correct and incorrect answers. Working interaction is welcome, but a convincing static design is acceptable.
