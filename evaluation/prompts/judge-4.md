# Fourth judge prompt (round 5: vague briefs, skill v1.3)

Run on a fresh model 2 agent. Variants: for F and G, the model 2 baseline and model 2 with skill v1.3. Labels were counterbalanced (the baseline is V1 in F and V2 in G); mapping in `../judge-review-4.md`. F images: desktop full page, desktop first screen, phone-width first screen. G images: desktop full page, desktop first screen, and a full-page render on an emulated touch phone (iPhone 13 profile), so on-screen controls could be judged.

Instructions were the same as `judge.md`, with these changes: judge each variant as a response to the one-sentence brief as written ("would the person who wrote that sentence be glad to receive it?"); rate mobile behavior using the phone renders; say plainly when a difference is small; give a confidence (low / medium / high).
