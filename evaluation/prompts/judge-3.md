# Third judge prompt (clean re-test of skill v1.2)

Run on a fresh Opus 5.5 agent with screenshots relabeled V1–V3 in a seeded random order (mapping in `../judge-review-3.md`). Variants: for A and C, the Opus 5.5 baseline and Opus 5.5 with skill v1.2; for E, the same two plus the unmodified original. Desktop full page, desktop first screen and mobile first screen were provided for each.

Instructions were the same as `judge.md` (describe, rate on eight qualities, list template-like patterns, rank), with two additions: say plainly when a difference is small, and give a confidence (low / medium / high) for each ranking. For E the reviewer was asked to identify the original and judge how well each improvement keeps the stated aesthetic.
