# Flowstate — Public Forum Debate Coach

A self-contained, local-first Public Forum debate practice website.

## Run it
Open index.html in a modern browser. No install or build step is required.

## Included
- PF round room with default speech order and adjustable timers
- Pro and Con case outlines with claim, warrant, evidence plan, and impact fields
- Flow board for arguments, responses, extensions, and dropped issues
- Evidence library with full citation fields and manual verified/unverified status
- Crossfire question drills, notes, and a three-minute timer
- Speech studio with judge adaptation, word count, time estimate, and scaffolds
- Tournament checklist, practice log, progress view, and JSON import/export
- Browser storage for drafts and workspace state

## Data and evidence
Workspace data is stored in this browser profile. Export a JSON backup before clearing browser data or switching computers. This demo has no AI service, source fetcher, evidence verifier, account system, or cloud sync. A card is marked VERIFIED only when you manually check the full citation and source text against the original.

The default topic is the NSDA Public Forum November/December 2026 resolution. Confirm topic wording and tournament rules against your own invitation.
