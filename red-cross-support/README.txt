RED CROSS SUPPORT - UI CONCEPT

Open index.html in a modern browser. No installation, build process, account,
API keys, or backend are needed. All source and local images are in this folder.

Files:
  index.html  - Page structure and content
  styles.css  - Responsive visual design
  script.js   - Tabs, gift selection, preview dialog, and mobile navigation
  assets/     - Local concept photography from the American Red Cross

Features:
  Responsive desktop/mobile layouts; accessible keyboard-operated support tabs;
  one-time/monthly gift preview; preset/custom amounts; native modal with focus
  management and Escape dismissal; expandable questions; mobile navigation;
  reduced-motion support; links to official donation and volunteering resources.

This is an independent demonstration, not an official American Red Cross site.
No real payments, appointments, or personal information are processed. The
selected gift is a local UI preview and is not transferred to the official site.
There are no invented testimonials or monetary-to-impact claims.

The font stylesheet loads DM Sans and Manrope from Google Fonts when online.
System fonts provide fallbacks. Images, styles, and JavaScript are stored locally.
